# Анимации Титуса

В GLB находятся 14 отдельных Actions, запечённых на скелет с частотой 60 кадров/с. Они воспроизводятся Godot AnimationPlayer, с переходами между стойкой и движением. Это ключевые скелетные анимации; логика боя не вращает статичную фигурку целиком вместо анимации конечностей.

| Клипы | Назначение |
| --- | --- |
| idle_bolter, idle_sword | Стойка под весом брони и дыхание, отдельное положение рук для каждого предмета |
| walk_bolter, walk_sword | Тяжёлый шаг с переносом массы и опорой стопы |
| run_bolter, run_sword | Более низкая стойка, ускоренный перенос ног, подъём стопы и наклон корпуса |
| aim_bolter | Поднятое оружие, поддержка второй рукой |
| fire_bolter | Короткий импульс отдачи в руках и корпусе |
| reload_bolter | Манипуляция второй рукой, наклон оружия, восстановление магазина в конце |
| draw_bolter, draw_sword | Дотянуться до крепления, перенести предмет в руку, вернуться в стойку |
| sword_slash_left, sword_slash_right | Разные замахи и направления разворота корпуса, удар и возврат |
| sword_overhead | Поднятие оружия над головой, удар с переносом веса вниз, восстановление стойки |

## События

- Смена предметов между BoneAttachment3D выполняется на 0,52 с клипа draw, а управление возвращается после 1,05 с.
- Болтер: импульс выстрела на 0,035 с клипа; урон наносится после долёта трассера. Темп стрельбы ограничен 0,22 с между действиями.
- Перезарядка заканчивается через 2,1 с.
- Левый удар меча наносит урон на 0,43 с, правый — на 0,36 с, верхний — на 0,56 с; затем проигрывается возврат.
- Шаг согласован с WALK_SPEED 3,0 м/с и RUN_SPEED 6,4 м/с. При изменении скоростей необходимо согласовать скорость клипа или повторно запечь походку.

## Стопы

При запекании используется двухзвенная кинематическая модель ноги. В фазе опоры стопа движется назад относительно корпуса; в фазе переноса поднимается над землёй. Компенсация наклона голеностопа сохраняет плоскую постановку стопы. Проверка в Godot измеряет реальную позицию кости footR после импорта, а не только значения генератора.

Скорость из контроллера сглаживается; на коротких переходах и резкой смене направления небольшое скольжение возможно. Рельеф полигона плоский. Адаптация ступней к лестницам и неровной поверхности потребует дополнительного runtime IK.

## Редактирование

Откройте `tools/source/titus-rig.blend`. Actions доступны в Action Editor. Подготовленные клипы можно менять вручную и экспортировать GLB в `assets/models/titus.glb`. Запуск `tools/rig_and_animate.py` заново создаёт сгенерированный набор из подготовленного меша — ручные правки сначала сохраните отдельным Blender-файлом.
