# Проверка проекта Godot

Проверено в Godot 4.6.3.stable.official, Linux. Реальный рендер выполнен через OpenGL Compatibility / Mesa llvmpipe на виртуальном дисплее Xvfb. Скриншоты получены из Viewport Godot, а не сгенерированы по описанию.

- Импорт моделей, материалов, шрифтов и сцены прошёл без ошибок GDScript.
- `tests/smoke.gd`: **50 проверок, 0 ошибок** — запуск, шесть мишеней, реальный скин на 16 костей, 14 клипов и их треки, обход укрытия, движение, очередь приказов, стрельба и долёт снаряда, расход патронов, перезарядка, смена оригинальных предметов между креплениями, атака мечом, прямое управление и выбор позиции для огня.
- `tests/animation_quality.gd`: **22 проверки, 0 ошибок** — швы шести циклов, изменение поз костей, высота и обратное движение опорной стопы, реальное положение кончика меча в момент контакта трёх ударов.
- Известное предупреждение виртуального дисплея: драйвер Xvfb/llvmpipe не поддерживает смену VSync. На запуск и результаты проверок это не повлияло.

Команды:

```sh
godot --headless --path . --editor --import
godot --headless --path . --fixed-fps 60 --script tests/smoke.gd
godot --headless --path . --fixed-fps 60 --script tests/animation_quality.gd
```

Тесты подтверждают перечисленные свойства и функциональность полигона. Они не оценивают художественное качество анимации, не гарантируют отсутствие любого пересечения брони в промежуточных кадрах и не заменяют просмотр клипов при дальнейшей ручной полировке.

Переносимость: архив распакован в отдельный каталог /tmp, заново выполнен импорт без исходного .godot-кэша; повторно прошли все 50 функциональных и 22 анимационные проверки. В архиве отсутствуют HTML и JavaScript.
