# ТИТУС · Бастион VII

Нативный проект **Godot 4.6.3**, GDScript, рендерер Compatibility. В проекте используется синяя модель пользователя `model-ot-27-10-compressed.glb`. Меч и пистолет выделены из неё в отдельные меши. Временный зелёный боец не используется.

## Открыть и играть

1. Распакуйте архив проекта.
2. В Godot 4.6.3 выберите **Импорт → project.godot**.
3. Дождитесь импорта ресурсов и нажмите **F5**.

Главная сцена — `scenes/range.tscn`. Архитектура полигона сохранена в редактируемой сцене `scenes/architecture.tscn`: укрытия, стены, мишени, коллизии и материалы видны в редакторе. Для запуска не нужны Blender, Node.js, сервер, ключи API или подключение к интернету. Blender нужен только для редактирования и повторного запекания исходника анимаций.

## Что работает

- Камера стратегии сверху под углом; поворот, наклон, масштаб, возврат к бойцу.
- Выбор Титуса, движение, быстрый тяжёлый бег, очередь приказов и обход укрытий через AStarGrid2D.
- Прямой контроль бойца с ручным прицеливанием.
- Отдельные настоящее оружие модели и крепления руки/спины. Смена оружия выполняется во время клипа, а не мгновенным переключением видимости.
- Скелет на 16 костей, 14 запечённых клипов AnimationPlayer, плавное смешивание при смене состояний.
- Ходьба и бег с фазой опоры и переноса стопы; длина шага согласована со скоростью контроллера. Пыль, тяжёлые шаги и лёгкая реакция камеры.
- Болтер: магазин на 30 патронов, перезарядка, отдача, вспышки, гильзы, летящие трассеры, урон после попадания и проверка линии огня.
- Меч: левый и правый рубящие удары и удар сверху; отдельные замах, контакт, проведение и возврат. Урон срабатывает на событии контакта.
- Шесть мишеней с уроном и восстановлением через 8 секунд, укрытия, мини-карта, справочник управления, переключение звука, сброс полигона.

Это тренировочный полигон с одним бойцом. Сетевой режим, отряды, подбор предметов с земли, ответный огонь и полноценная система разрушений в эту версию не входят.

## Управление

| Действие | Клавиши |
| --- | --- |
| Выбрать бойца | ЛКМ по Титусу / рамка |
| Двигаться / атаковать мишень | ПКМ |
| Бег | Двойной ПКМ |
| Добавить точки маршрута | Shift + ПКМ |
| Режим атаки / движения | A / M |
| Болтер / меч | 1 / 2 |
| Перезарядка / стоп | R / H |
| Прямой контроль | Ctrl |
| Движение в прямом режиме | WASD, Shift — бег |
| Стрельба / удар в прямом режиме | ЛКМ / удержание |
| Переместить камеру | Стрелки |
| Повернуть и наклонить камеру | Зажать СКМ |
| Масштаб / к бойцу | Колесо / Пробел |
| Справочник / закрыть | F1 / Esc |

В интерфейсе доступны те же основные приказы. Звук включается в верхней панели. Оружие не меняется посреди удара: сначала завершается действие.

## Модель и анимации

- `assets/models/titus.glb` — готовый игровой персонаж: скин, отдельное оружие, маркеры дула и кончика меча, 14 скелетных клипов.
- `assets/models/titus-separated.glb` — подготовленная модель до рига, 65 000 треугольников брони + 7 000 меча + 6 000 пистолета.
- `tools/source/titus-rig.blend` — редактируемый Blender-исходник со скелетом, весами и Actions; исключён из автоматического импорта Godot через `.gdignore`.
- `tools/rig_and_animate.py` — воспроизводимое запекание клипов в Blender 4.3.2. Команда из корня: `blender -b -t 6 -P tools/rig_and_animate.py`.
- `docs/ANIMATIONS.md` — список клипов, события и схема движения.

Исходное вложение не изменялось. Из единого меша выделена геометрия обоих предметов с сохранением текстуры. Риг и движения созданы для этого прототипа, без готовых анимаций в исходном файле. Мелкая артикуляция пальцев и лица отсутствует; кулаки модели остаются частью общего скина. Силовая броня, ремни и ткань деформируются скелетом, отдельной симуляции ткани нет.

## Проверки

```sh
godot --headless --path . --editor --import
godot --headless --path . --fixed-fps 60 --script tests/smoke.gd
godot --headless --path . --fixed-fps 60 --script tests/animation_quality.gd
```

Первая функциональная проверка содержит 50 проверок: запуск, модель и клипы, маршруты, бой, смена креплений, патроны, перезарядка, ближний бой, прямое управление и поиск огневой позиции. Вторая содержит 22 проверки: швы циклов, изменение поз костей, высота опорной стопы и движение стопы относительно корпуса. Результаты фиксируются в `docs/VALIDATION.md`.

Обычный запуск: `godot --path .`. Снимок из реального рендера: `godot --path . -- --capture`; изображение сохраняется в `docs/godot-range.png`. Для крупного плана клипа: `godot --path . -- --capture --showcase --clip=sword_slash_left`.

Среда уже изолирована. Используйте существующий checkout, не создавайте Git worktree без явного запроса пользователя.

При перемещении укрытий в редакторе синхронизируйте прямоугольники COVER в scripts/navigation.gd с их коллизиями. Для пересоздания архитектуры из генератора: godot --headless --path . --script tools/bake_world.gd.
